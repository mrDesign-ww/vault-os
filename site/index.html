Guards

Safe by default.

Hooks sit between the agents and your machine. They stop the few actions that are hard to undo.

If a guard itself fails, the action goes through: a broken guard never blocks your work.

  • Blockedpkill -f nodeStop only processes you started, by their id.
  • Blockedrm -rf build/*No deletes by glob pattern.
  • Pausedweekly usage 98%Work stops, a handoff note is written, and it resumes after the reset.
  • Blockedread screenshot.png · 3200 pxOn macOS, builder agents get images up to 1600 px. Visual reviewers see full size.
  • Keptcontext compactionThe chat is summarized to free room. Your last messages, agents and state files stay.

Memory

Memory with levels of trust.

Folders say where a note lives. Levels say how far an agent may trust it.

  • Agents load policy (L3) first, then canonical pages (L2), then facts (L1). Evidence (L0) only on demand.
  • Memory an agent infers starts as evidence, outside retrieval, until it is verified.
  • Each zone (work, personal, client) has its own index. If an index is stale, retrieval gives no answer rather than an old one.
  • Claude and Codex share memory only through the vault, never by copying each other's internals.

Evolution

Upkeep that waits for your word.

One command runs a hygiene pass over memory and the wiki. A read-only verifier checks the result before anything counts.

Done

Curator

Audits memory and finds pages at the wrong trust level. Makes only safe fixes and proposes the rest.

Hygiene

One zone at a time, under a lock: dead links, unlinked pages, stale claims. Long logs get a summary; nothing is deleted.

Retrieval refresh

Rebuilds the indexes, validates them, then checks them with a live query.

Verifier

Read-only. Checks that zones stay apart, that no data leaves, that it can be undone and that evidence is kept.

Pass · facts (L1) and canonical pages (L2) update

Policy changes wait for you

  • Learning from past sessions (reflection) is off by default. Turning it on needs your word.
  • Each zone (work, personal, client) is processed on its own. Client data stays on your machine.
  • A procedure that keeps repeating becomes a draft skill you approve.
  • It can propose a policy rule. Only you can approve one.

What it changes

  • Backs up your Claude and Codex settings before it changes anything.
  • Replaces an older system and keeps every personal file. One command rolls it back.
  • Bypass permissions stay off unless you turn them on.

What you get

  • 10 agent types in three model tiers
  • Memory with four trust levels
  • A design layer for UI/UX and frontend
  • 74 bundled skills, guard hooks and evolution
