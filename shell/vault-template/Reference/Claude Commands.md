# Claude Commands (шпаргалка)

Команды плагина **claude-obsidian**. Вызываются в **Claude Code** (терминал), не в самом Obsidian. Запускай Claude из корня этого vault:

```
cd <path-to-your-vault>
claude
```

Можно набрать `/` и выбрать из списка, либо написать триггер-фразу обычным текстом (во втором столбце примеры).

---

## Настройка и навигация

| Команда | Когда / как звать | Что делает |
|---|---|---|
| `/wiki` | "проверь хранилище", "setup" | Настройка/проверка vault, маршрутизация к под-скилам |
| `/wiki-mode` | "какой режим", "switch to PARA" | Организационный режим (LYT / PARA / Zettelkasten / Generic). У нас **PARA** |

## Добавить знание

| Команда         | Когда / как звать                                         | Что делает                                                                                                               |
| --------------- | --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `/wiki-ingest`  | "ingest [путь]", "занеси это", "добавь в вики"            | Читает источник, вытягивает сущности/концепты, создаёт страницы, кросс-ссылки, лог                                       |
| `/defuddle`     | "очисти эту страницу", "clean this url"                   | Чистит веб-страницу от рекламы/навигации до читаемого markdown (экономит 40–60% токенов) перед ingest                    |
| `/autoresearch` | "research [тема]", "deep dive into [тема]", "go research" | Автономный цикл: веб-поиск → синтез → раскладка по страницам вики                                                        |
| `/save`         | "save this", "сохрани", "/save"                           | Сохраняет текущий разговор/инсайт как структурированную заметку (у нас уйдёт в `projects/inbox/`, потом в нужный проект) |

> Это **не дубль кода** плагина, а справочник. Сами команды живут в Claude Code (установлены глобально) и работают из любой папки. Если плагин обновится и список изменится, обнови эту страницу (или попроси Claude: "обнови шпаргалку команд").
